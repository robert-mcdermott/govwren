API reference

Every endpoint of the JSON API, generated from GovWren's OpenAPI document for version 0.6.0. For conventions, sign-in, and examples, see The API. A running instance serves the same reference at /api/docs and the document itself at /api/openapi.json.

System#

GET /api/v1/health/live#

Is the server process running?

GET /api/v1/health/ready#

Can the server do its work?

The database answers and its schema is the one this version expects.

Scheduled work, and how its recent runs went

Pause or resume one job

ParameterInTypeRequiredMeaning
keypathstringyes

POST /api/v1/jobs/{key}/run#

Run one job now

Runs the job at once, whether or not it is due, and says what it did. If another process is running it at this moment, nothing is run and the answer says so.

ParameterInTypeRequiredMeaning
keypathstringyes

GET /api/v1/mail#

How email is set up, and how it is doing

POST /api/v1/mail/test#

Send yourself a test message

GET /api/v1/meta#

The product's name, version, and branding

What the web app needs before anyone signs in.

GET /api/v1/operations#

How the installation is running

One page for whoever keeps the server: the checks `govwren doctor --production` makes, with scheduled work, email, webhooks, the last backup, and the size of things.

POST /api/v1/imports/records/{kind}#

Import records from CSV

Send the CSV as the request body. ``kind`` is ``systems``, ``models``, ``datasets``, or ``vendors``. With ``dry_run`` (the default) nothing is changed; without it, nothing is changed unless every row is good.

ParameterInTypeRequiredMeaning
kindpathstringyes
dry_runquerybooleanDefault: true.
mappingquerystringJSON: which column is which field, as {column: field}. Left out, GovWren guesses by name and returns its guess.
